# ライブ翻訳ノート（開発中・名称未定）

海外の講演やウェビナーの英語音声を、ブラウザだけでリアルタイムに日本語訳・要約するWebページです。
サーバーやAPIの費用はかからず、ブラウザに内蔵されたAI（Chrome／Edge）で動きます。

## ファイル構成
| パス | 内容 |
|---|---|
| `index.html` | 本体の画面 |
| `check.html` | 動作確認の画面（ブラウザのバージョン、各機能の利用可否、音声認識の実地テスト） |
| `css/` | 見た目（`theme.css` は共通の色設定） |
| `js/app.js` | 本体の処理 |
| `js/check.js` | 動作確認の処理 |
| `data/glossary.csv` | 初期の用語集（英語, 日本語訳, 分野, メモ） |

開発用の資料（引き継ぎ書・試作版）は `docs/` に置いていますが、公開しないため .gitignore で除外しています（開発者のPCにだけあります）。

## 手元で開く
ビルドは不要です。マイクや内蔵AIは `https` か `localhost` でないと動かないため、簡易サーバーで開きます。

```bash
npx --yes http-server -p 8765 -c-1
```

ブラウザで `http://localhost:8765/` を開きます。

`check.html`（動作確認）だけは、ファイルをダブルクリックして直接開いても動きます。ただしその場合、音声認識や内蔵AIの結果は https で開いたときと違うことがあるので、参考値として扱ってください。

## 秘密情報について
外部AI（高品質モード）のAPIキーは利用者のブラウザ内にだけ保存します。コードやこのリポジトリには入れません。
